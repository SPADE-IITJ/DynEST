# Archived OpenMP benchmark results

This directory contains the parallel/OpenMP archive corresponding to the
synthetic streams and `CollegeMsg_window604800`. It has the same five CSV
series and column definitions described in [results/README.md](../results/README.md).
It does not contain the paper's complete ten real-world dataset evaluation.

Timings are machine- and thread-configuration-dependent. Use a separate
`--out-dir` such as `reproduced_results/` for new benchmark runs.
